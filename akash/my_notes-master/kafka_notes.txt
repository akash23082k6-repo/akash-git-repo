>> Kafka : It is distrubuted messaging streaming platform uses publish and subscribe mechaism to stream records.

 It is originally developed by Linkedin , later pass on to Apache foundation . 

## Messaging streaming 
        1. Point to Point ( messages are deleted once received by receiver , no time limit for receiver to consume the message, receiver send acknowledgment after receiving the message. 
        2. Publish and subscribe ( message are stored in topic, time limit for receiver to consume the message, receiver don’t send acknowledgement after receiving the message.)




## Installation of zookeeper and Kafka 

To start zookeeper : need to run  zkServer.sh , location /bin   —> it will look for config file in conf/ —> zoo.cfg 

Zoo.cfg 
tickTime=2000
initLimit=10
syncLimit=5
dataDir=/tmp/zookeeper
clientPort=2181
maxClientCnxns=60
4lw.commands.whitelist=*

## echo stat | nc localhost 2181   — to check zookeeper status 

## To start/stop  Kafka : need to run below script at bin/
kafka-server-stop.sh
kafka-server-start.sh

bin/kafka-server-start.sh -daemon config/server.properties —> to start Kafka in background . 

For Kakfa to run it will look for server.properties in conf/

broker.id=1
listeners=PLAINTEXT://localhost:9092

 ## echo dump | nc localhost 2181 | grep brokers — to check brokers 

## To check Kafka logs : /logs/server.log

tail -100f server.log —> to check logs
