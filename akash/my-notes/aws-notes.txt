 ##### What is AWS ####
 
 AWS (Amazon Web Services) is a cloud platform provided by Amazon that gives you IT resources over the internet.
 
 In simple words:

AWS is like renting computers, storage, databases, networking, and other IT services from Amazon instead of buying and maintaining your own physical servers.

#### Why do we need AWS? ####

AWS helps companies :-1. Reduce infrastructure setup time 
                      2. Scale application
                      3. Pay based on usage for many services 
                      4. Iprove availability
                      5. Automate infrastructure
                      6. Deploy applications globally
                      7. Build disaster-recovery solutions

#### How AWS works ####

AWS hides most of the physical infrastructure from you.

You interact with AWS through:

* AWS Management Console
* AWS CLI
* SDKs
* APIs
* Infrastructure-as-Code tools such as Terraform

Load balancer :- it Distributes traffic to multiple server/EC2 instance
                 Instead of users directly accessing one EC2:

                          Users
                            ↓       
                           EC2

                we use:

                                 ┌── EC2-1
                    Users → ALB ─┼── EC2-2
                                 └── EC2-3

The Load Balancer receives the request and forwards it to an appropriate backend server.

AWS provides this functionality through Elastic Load Balancing (ELB).


Why do we need a Load Balancer?

Suppose your application has only one EC2:

1000 Users
     ↓
   EC2-1

Problems:

* EC2 can become overloaded
* If EC2 fails, application may become unavailable
* Difficult to handle traffic spikes
* No easy distribution of traffic

With a Load Balancer:

                 ┌── EC2-1
1000 Users → ALB ├── EC2-2
                 └── EC2-3

Traffic is distributed among the available servers.



Main benefits
1. High Availability

Traffic can be distributed across multiple EC2 instances and Availability Zones.

2. Scalability

Works with Auto Scaling.

When demand increases:

2 EC2 → 4 EC2

The Load Balancer can send traffic to the new instances after they become healthy targets.

3. Fault tolerance

If an instance becomes unhealthy, the Load Balancer can stop sending new traffic to it.

4. SSL/TLS termination

You can configure HTTPS at the Load Balancer.

User
 ↓ HTTPS
ALB
 ↓ HTTP/HTTPS
EC2

This can reduce the need to handle TLS directly on every backend server.

##### How Load Balancer works

A simplified flow:

              Internet
                 │
                 ↓
          Load Balancer
                 │
        ┌────────┼────────┐
        ↓        ↓        ↓
      EC2-1    EC2-2    EC2-3

Suppose 3 users send requests:

Request 1 → EC2-1
Request 2 → EC2-2
Request 3 → EC2-3

                                            RDS :-(relational database service)

RDS is an AWS services that create,manage,and run relational database without managing the database server yourself.

Common databases supported by RDS :-

    MySQL
    PostgreSQL
    MariaDB
    Oracle
    Microsoft SQL Server
    Amazon Aurora


why do we use RDS ?

without RDS :- you could install MySQL on an EC2 instance yourself 

    EC2 → Install MySQL → Configure → Patch → Backup → Monitor → Secure

with RDS :- application → RDS Database    

AWS handles many infrastructure tasks such as:-

     Automated backups
     Software patching
     Monitoring
     High availability options
     Database recovery
     Storage management
     Scaling options
     Security integration with VPC and IAM



RDS vs EC2 with MySQL


| Feature        | RDS                   | MySQL on EC2    |
| -------------- | --------------------- | --------------- |
| Database setup | AWS-managed           | You manage      |
| Backups        | Automated options     | You configure   |
| Patching       | AWS-managed options   | You manage      |
| Maintenance    | Less                  | More            |
| Control        | Less OS-level control | Full OS control |
| DevOps effort  | Lower                 | Higher          |
