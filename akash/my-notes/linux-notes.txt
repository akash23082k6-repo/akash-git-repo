###### pipe command ->> connects the output of one command directly to the input of another command

    ls -la /etc -->> this show to long , difficult to read
    ls -la /etc | less -->> this show low at a time easy to read


##### TEE command -->> reads standard input and writes it to both standard output (your terminal screen) and one or more files at the same time.

    ls | tee <filename>
    ls -la /etc | tee etc_listing.txt | grep "conf" -->>this command does three things:

1. It lists the contents of the /etc directory.
2. It pipes that output to tee, which saves a copy to etc_listing.txt and also passes it along.
3. The output from tee is then piped to grep, which filters for lines containing "conf".

###### umask ######

it controls the the default permissions given to the new file/directory

it is use to remove or modify default permissions of a file/directories

file:-->> 666
directories-->> 777

for example:-- umask 22

new directory :- 777-022 = 755 result -->> drwxr-xr-x


#### TAR AND GZIP ####

TAR:- combines multiple files and directories into a single archive

tar cvf myarchive.tar file1 file2 directory1

c: create a new archive.
v: verbose mode, which lists the files as they are processed.
f: file, which specifies that the next argument is the name of the archive file.

tar xzvf myarchive.tar.gz

x: extract files from an archive.
z: Decompress the archive using g**z**ip.
v: verbose mode, listing files as they are extracted.
f: file, specifying the archive file to extract.

#### Vim Navigation ####

h or the left arrow - will move you left one character
j or the down arrow - will move you down one line
k or the up arrow - will move you up one line
l or the right arrow - will move you right one character

x – Deletes the character directly under the cursor.
dw – Deletes from the cursor to the beginning of the next word.
d$ – Deletes from the cursor to the end of the current line.
dd – The dd command deletes the entire current line.
3dd – Deletes three lines, starting from the current line.

cw – Changes the text from the cursor to the end of the word.
c$ – Changes text from the cursor to the end of the line.
cc – Changes the entire current line.

yw – Yanks (copies) a word.
yy – Yanks the entire current line.
p – Puts (pastes) the yanked text after the cursor or on the line below.
P – Puts the text before the cursor or on the line above.
