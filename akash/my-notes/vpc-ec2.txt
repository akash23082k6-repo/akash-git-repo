to add tag to already existing server: 

aws ec2 create-tags \
  --resources i-0a4d8d11739add206 \
  --tags Key=Name,Value=Ubuntu-Server


to launch instance with public and name tag:
  aws ec2 run-instances \
  --image-id ami-01a00762f46d584a1 \
  --instance-type t3.micro \
  --key-name my-key \
  --security-group-ids sg-06164cc2a4fe3fd8b \
  --subnet-id subnet-0f9d14c035ac17143 \
  --associate-public-ip-address \
  --count 1 \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=my-Public-server}]'

-->>run -->>make folder--->> tap on instance-->> image and templets-->> create image

snapshots:- backups/copy

EBS encryption key :- 

always use custom key for encrypt EBS volume

to change encryption key :-

AMI → Copy AMI → choose KMS new Key  → use the new AMI.


Go to AWS Console → EC2 → AMIs
Select the AMI you want to change.
Click Actions → Copy AMI.
Select the Destination Region.
Under encryption, enable Encrypt EBS snapshots.
Select your new KMS key.
Click Copy AMI.
Wait until the copied AMI becomes Available.

                                                        AWS IAM (identity access Management)
                                                      

it is used to control who can access aws resource and what allowed to do 


  IAM MAIN COMPONENTS

  user :- represent a person/application needing AWS access
  group:- collection of user 
  policy :- rules that allow or deny Actions
  role :- temprorary permissions to user 
  permission :- what action is allowed or denied
